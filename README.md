# pollinating sandboxes
*pollinating sandboxes* is a Minecraft modpack rooted in TerraFirmaCraft (TFC) to combine Create Mods (including Create Aeronautics) and select mods to facilitate a technical progression as inspired by the quote, "Per aspera ad astra - Through hardships to the stars." Further direction is best stated by *All The Mods - Gravitas²*, "You will voyage from a primitive beginning, smashing rocks together, to smashing atoms together, to power your voyages to the stars and beyond!"

At this stage of development, the toolchain and processes to create this modpack are being established on a *development* branch to be incorporated into the *main* branch as decisions towards an alpha release become stable.
